트랜지스터 모터 제어

브라우저에서 9번 핀(PWM)으로 트랜지스터 스위치를 켜고 끄며 모터 속도를 조절합니다. Chrome·Edge 필요.

1. 연결

연결 안 됨

먼저 아래 4번의 스케치를 보드에 업로드하세요. 업로드할 때는 Arduino IDE의 시리얼 모니터를 닫아 둬야 포트가 열립니다.

2. 회로 (C1815, NPN + 6V 건전지 + 다이오드)

트랜지스터는 글자가 있는 평평한 면을 나를 향하게 하고 다리를 아래로 둔 상태에서 왼쪽부터 E - C - B.

#시작부품끝
①건전지 6V (+)직접 연결모터 한쪽 단자
②모터 다른 쪽 단자직접 연결트랜지스터 C (가운데)
③트랜지스터 E (왼쪽)직접 연결건전지 (−)
④건전지 (−)직접 연결아두이노 GND
⑤아두이노 9번 핀1kΩ 저항트랜지스터 B (오른쪽)
⑥다이오드 줄무늬(캐소드)모터와 병렬줄무늬 → 건전지 (+) 쪽, 반대쪽 → 트랜지스터 C 쪽

전류 길: 건전지 (+) → 모터 → C → E → 건전지 (−). 신호선: 9번 핀 → 1kΩ → B. 아두이노 5V 선은 쓰지 않습니다.

다이오드 방향: 줄무늬가 건전지 (+) 쪽이어야 합니다. 반대로 달면 합선됩니다. GND 공통 연결(④)을 빼먹으면 동작하지 않습니다.

3V 모터에 6V는 과전압이라 속도를 약 50% 이하로 두고 쓰세요. C1815는 최대 약 150mA이므로 모터가 힘이 약하거나 트랜지스터가 뜨거우면 더 큰 트랜지스터(TIP120, 2N2222 등)로 바꾸세요.

3. 모터 제어

OFF (정지)
50%

ON = 9번 핀에 PWM 출력 → 트랜지스터가 빠르게 켜졌다 꺼지며 모터 평균 전압이 속도 값에 비례. OFF = 0V → 트랜지스터 OFF → 모터 정지. 슬라이더는 모터가 켜진 상태에서 바로 반영됩니다.

4. 보드에 올릴 스케치

#define MOTOR_PIN 9   // PWM 핀 (우노: 3, 5, 6, 9, 10, 11)

String line;

void setup() {
  Serial.begin(9600);
  pinMode(MOTOR_PIN, OUTPUT);
  analogWrite(MOTOR_PIN, 0);
}

void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == '\n') { handle(line); line = ""; }
    else if (c != '\r') line += c;
  }
}

void handle(String s) {
  if (s == "L") {                     // 정지
    analogWrite(MOTOR_PIN, 0);
    Serial.println("OK STOP");
  } else if (s.startsWith("P")) {     // P0 ~ P255 : PWM 듀티
    int v = constrain(s.substring(1).toInt(), 0, 255);
    analogWrite(MOTOR_PIN, v);
    Serial.print("OK PWM ");
    Serial.println(v);
  }
}
